# Сценарии

Выбраны два варианта использования: самый ценный для бизнеса («Завершить
аренду» — это точка, где фиксируется выручка и штрафы) и самый рискованный в
реализации («Открыть автомобиль по телефону» — зависит от связи, геолокации
и безопасности доступа).

## ВИ-04. Открыть автомобиль по телефону

**Актёры:** Клиент (первичный), Бортовой модуль автомобиля

**Цель:** получить физический доступ в салон забронированного автомобиля без
ключа, используя номер телефона как идентификатор

**Предусловия:** у клиента есть активная бронь на этот автомобиль; клиент
находится рядом с автомобилем; на телефоне есть связь

**Постусловия (успех):** двери автомобиля разблокированы; бронь переведена в
статус «в аренде»; создана запись «Аренда» с временем начала

**Постусловия (неуспех):** автомобиль остаётся заблокированным; статус брони
не меняется

**Тип:** базовый

**Связи:** include ВИ-11 «Аутентифицировать пользователя»

### Основной сценарий

| # | Действие актёра | Отклик системы |
|---|---|---|
| 1 | Клиент нажимает «Открыть» в приложении, привязанном к номеру телефона | 2. Система проверяет, что у клиента есть активная бронь именно на этот автомобиль |
| 3 | — | 4. Система аутентифицирует клиента по номеру телефона и токену сессии |
| 5 | — | 6. Система отправляет бортовому модулю автомобиля команду разблокировки |
| 7 | — | 8. Бортовой модуль подтверждает разблокировку и передаёт текущие координаты |
| 9 | — | 10. Система переводит бронь в статус «в аренде», создаёт запись аренды с временем начала |
| 11 | Клиент садится в автомобиль и уезжает | 12. Система показывает клиенту экран активной аренды |

### Исключения

**И-1. Нет связи у бортового модуля** (шаг 6)

Команда не доходит до автомобиля за отведённое время (10 секунд). Система
показывает клиенту сообщение «Автомобиль временно недоступен» и предлагает
повторить попытку или обратиться в поддержку. Бронь остаётся активной.

**И-2. Клиент не рядом с автомобилем** (шаг 2)

Система сверяет координаты телефона клиента и автомобиля; если расстояние
больше 50 метров, разблокировка отклоняется, клиенту показывается расстояние
до автомобиля.

**И-3. Бронь истекла к моменту попытки открыть** (шаг 2)

Система показывает причину отказа и предлагает оформить новую бронь на этот
же автомобиль, если он ещё свободен.

**И-4. Автомобиль уже открыт другим сеансом (гонка команд)** (шаг 6)

Бортовой модуль возвращает признак «уже разблокирован кем-то другим»; система
блокирует повторную выдачу доступа и передаёт инцидент оператору поддержки.

### Примечания

Таймаут ожидания ответа от бортового модуля — 10 секунд, после чего попытка
считается неуспешной автоматически (см. доменную модель, часть 3).

## ВИ-05. Завершить аренду

**Актёры:** Клиент (первичный), Бортовой модуль автомобиля, Оператор
поддержки

**Цель:** зафиксировать окончание поездки, рассчитать стоимость по фактическому
времени аренды и, если нужно, начислить штраф

**Предусловия:** у клиента есть аренда в статусе «в аренде»

**Постусловия (успех):** аренда закрыта с временем окончания; рассчитана и
списана стоимость поездки; автомобиль переведён в статус «свободен» (если в
зоне завершения) или «требует эвакуации» (если вне зоны)

**Постусловия (неуспех):** аренда остаётся открытой, тарификация продолжает
идти

**Тип:** базовый

**Связи:** include ВИ-06 «Проверить зону завершения аренды»; include ВИ-07
«Рассчитать стоимость поездки»; extend ВИ-10 «Начислить штраф»

### Основной сценарий

| # | Действие актёра | Отклик системы |
|---|---|---|
| 1 | Клиент нажимает «Завершить аренду» в приложении | 2. Система запрашивает у бортового модуля текущие координаты и пробег |
| | | 3. Система проверяет, попадают ли координаты в одну из зон завершения аренды |
| | | 4. Система рассчитывает длительность аренды в минутах и стоимость по действующему тарифу |
| | | 5. Система списывает стоимость выбранным способом оплаты |
| | | 6. Система закрывает запись аренды, переводит автомобиль в статус «свободен» |
| 7 | — | 8. Система показывает клиенту итоговый чек: время, стоимость, способ оплаты |

### Исключения

**И-1. Автомобиль завершён вне зоны завершения** (шаг 3)

Система создаёт штраф за завершение аренды вне зоны (переход к ВИ-10),
переводит автомобиль в статус «требует эвакуации» вместо «свободен» и
уведомляет оператора поддержки.

**И-2. Списание не прошло (карта отклонена)** (шаг 5)

Система всё равно закрывает аренду по времени, помечает задолженность как
«не оплачена», блокирует новые брони клиента до погашения долга и повторяет
попытку списания через сутки.

**И-3. Бортовой модуль не отвечает на запрос координат** (шаг 2)

Система использует последние известные координаты не старше 3 минут; если
таких нет — аренда закрывается с пометкой «требует ручной проверки
оператором», зона не подтверждена.

**И-4. Обнаружено повреждение по итогам фотоотчёта** (после шага 6)

Клиент обязан приложить фото салона перед выходом; если система/оператор
находит повреждение, создаётся штраф за повреждение (переход к ВИ-10) уже
после закрытия основной аренды.

### Примечания

Расчёт стоимости не является отдельным диалогом с клиентом — это внутреннее
поведение системы, срабатывающее автоматически при завершении аренды.
