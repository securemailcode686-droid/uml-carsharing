# Трассировка на требования (FURPS+)

| ВИ | Функциональное | Нефункциональное (категория FURPS+) |
|---|---|---|
| ВИ-01 Найти автомобиль поблизости | поиск свободных авто в радиусе от геопозиции клиента | отклик карты < 1 с при 5000 активных авто *(Performance)* |
| ВИ-02 Забронировать автомобиль | бронь авто на 15 минут бесплатного ожидания | бронирование не более чем за 3 действия в приложении *(Usability)* |
| ВИ-03 Отменить бронь | отмена брони и освобождение авто | авто возвращается в поиск не позднее 5 с после отмены *(Performance)* |
| ВИ-04 Открыть автомобиль по телефону | разблокировка по команде через бортовой модуль | до 3 повторов команды при потере связи, итоговый ответ ≤ 10 с *(Reliability)* |
| ВИ-05 Завершить аренду | закрытие аренды, расчёт, проверка зоны | чек показан клиенту ≤ 5 с после нажатия «Завершить» *(Performance)* |
| ВИ-06 Проверить зону завершения | проверка попадания координат в полигон зоны | точность проверки не хуже 10 м *(+ физические ограничения GPS)* |
| ВИ-07 Рассчитать стоимость поездки | стоимость = минуты × тариф | новый тариф подключается без выпуска новой версии приложения *(Supportability)* |
| ВИ-08 Оплатить поездку | списание стоимости поездки | повторное списание по одной аренде исключено (идемпотентность) *(Reliability)* |
| ВИ-09 Оплатить картой | списание через платёжный шлюз | данные карты не хранятся в системе, только токен (PCI DSS) *(+ ограничение интерфейсов)* |
| ВИ-10 Начислить штраф | начисление штрафа по причине | история штрафов хранится 3 года для разбора жалоб *(Supportability)* |
| ВИ-11 Аутентифицировать пользователя | вход по номеру телефона и SMS-коду | блокировка на 15 минут после 5 неверных кодов *(+ Security)* |
| ВИ-12 Оплатить бонусным счётом | списание с внутреннего баланса | баланс не уходит в минус при параллельных списаниях *(Reliability)* |

Смысл упражнения: диаграмма ВИ покрывает только букву F из FURPS+; требования
к скорости, надёжности, сопровождаемости и ограничения фиксируются отдельно.
