# Трассировка на требования (FURPS+)

| ВИ | Функциональное | Нефункциональное (категория FURPS+) |
|---|---|---|
| ВИ-01 Найти автомобиль поблизости | поиск свободных авто в радиусе от геопозиции клиента | отклик карты < 1 с при 5000 активных авто *(Performance)* |
| ВИ-04 Открыть автомобиль по телефону | разблокировка по команде через бортовой модуль | команда должна дойти до автомобиля даже при кратковременной потере связи (retry до 3 раз) *(Reliability)* |
| ВИ-05 Завершить аренду | расчёт стоимости и проверка зоны при завершении | итоговый чек формируется и показывается клиенту не дольше 5 секунд после нажатия «Завершить» *(Performance)* |
| ВИ-10 Начислить штраф | автоматическое начисление штрафа по причине | все начисленные штрафы храним и можно поднять историю за 3 года для разбора жалоб *(Supportability)* |

Смысл упражнения: показать, что диаграмма ВИ покрывает только букву F из
FURPS+, а требования к отклику, отказоустойчивости связи и хранению истории
нужно фиксировать отдельно.
