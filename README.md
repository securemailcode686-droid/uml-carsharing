# Сервис каршеринга «ГоуКар»

Мобильный сервис краткосрочной аренды автомобилей поминутно. Пользователь через
мобильное приложение находит свободный автомобиль поблизости, бронирует его на
ограниченное время, открывает дверь по номеру телефона (без физического ключа —
приложение отправляет команду разблокировки на бортовой модуль автомобиля) и
управляет им. Стоимость поездки считается по фактическому времени аренды
(тарификация по минутам). Аренда должна быть завершена в одной из размеченных
на карте зон завершения — если автомобиль оставлен вне зоны, система
автоматически начисляет штраф. Штрафы также начисляются за повреждения и
нарушение правил эксплуатации. Оплата проходит через внешний платёжный шлюз
(при оплате картой) либо списывается с внутреннего бонусного счёта клиента.

Система используется частными клиентами (водителями) и операторами поддержки,
которые разбирают спорные ситуации (штрафы, отмены, технические проблемы).

Границы системы: бэкенд сервиса (бронирование, тарификация, штрафы, учёт
парка) и мобильное приложение клиента. Вне системы: сама физическая
инфраструктура автомобиля (двигатель, механика), платёжный шлюз как таковой
(внешний сервис), спутниковая GPS-инфраструктура.
